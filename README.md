`Python` · `Scikit-learn` · `Streamlit` · `Risk Analytics`

`Python` · `XGBoost` · `Machine Learning` · `Fraud Detection`

`Econometrics` · `ARDL` · `VAR/VECM` · `Time Series`

Microeconometric analysis of education and high-skill employment in the Netherlands using IPUMS census data, Logit models, and marginal effects.
